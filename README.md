# 🍪 Auto Cookie Run

บอทออโต้สำหรับ **CookieRun: OvenBreak** บนอีมูเลเตอร์ (LDPlayer / MuMu) ใช้ฟาร์มกล่อง
กดเริ่มเกมเอง วิ่งจนจบ กด OK เปิดกล่อง แล้ววนรอบใหม่ไปเรื่อยๆ

โปรเจกต์นี้เป็น **open source** ดูโค้ดได้ทุกบรรทัด ไม่แก้ไฟล์เกม ไม่ใช้ ADB

> ⚠️ ใช้บอทกับเกมออนไลน์อาจผิดข้อตกลงการใช้งานของเกม ผู้ใช้รับความเสี่ยงเอง

## ดาวน์โหลด (สำหรับคนทั่วไป)

1. ไปที่หน้า [**Releases**](../../releases/latest) แล้วดาวน์โหลดไฟล์ `.zip` ล่าสุด
2. แตกไฟล์ไว้ในโฟลเดอร์ไหนก็ได้ แล้วเปิด `CookieRunBasicMouse_v*.exe`
3. ถ้า Windows ขึ้น **"Windows protected your PC"** ให้กด **More info** แล้วกด **Run anyway**
   - ขึ้นแบบนี้เพราะโปรแกรมไม่ได้ซื้อใบรับรองดิจิทัล (code signing) ไม่ได้แปลว่ามีไวรัส
   - ถ้าไม่มั่นใจ ดูโค้ดในหน้านี้ หรือ build เองตามหัวข้อด้านล่างได้เลย

## วิธีใช้

1. เปิดเกมในอีมู (LDPlayer หรือ MuMu) ไว้ที่หน้าล็อบบี้ที่มีปุ่ม **Play**
2. เปิดโปรแกรม บอทจะหาหน้าต่างอีมูให้เอง
3. เลือกปุ่มที่อยากให้บอทกด (PLAY, OK, OPEN ALL, CONFIRM ...) แล้วกด **เริ่มทำงาน**
4. ตั้ง **หยุดหลังจบ X รอบ** ได้ (0 = ไม่จำกัด)
5. กด **F8** เพื่อพัก / ทำงานต่อ เวลาอยากเล่นเอง

ไม่ต้องย่อหน้าต่างอีมู และไม่ต้องให้อีมูอยู่หน้าสุด เมาส์จริงไม่ถูกบอทใช้ ใช้คอมทำอย่างอื่นได้

### อัปเดตเวอร์ชันใหม่

ตั้งแต่ v2.18.20 เปิดโปรแกรมแล้วจะเช็กเวอร์ชันใหม่จาก GitHub ให้เอง ถ้ามีจะถามก่อนว่าจะอัปเดตไหม
(หรือกดปุ่ม **⟳ อัปเดต** มุมขวาบน) โปรแกรมจะดาวน์โหลด ตรวจไฟล์ด้วย SHA-256 แล้วเปิดเวอร์ชันใหม่ให้
การตั้งค่าและ Telegram ใช้ต่อได้เหมือนเดิม ส่วนไฟล์เวอร์ชันเก่าจะถูกลบให้อัตโนมัติ

ถ้าใช้ v2.18.19 อยู่ ต้องดาวน์โหลดเวอร์ชันใหม่จากหน้า Releases เองอีกครั้งเดียว

### แจ้งเตือน Telegram (ไม่บังคับ)

ถ้าเกมค้าง บอทส่งแจ้งเตือนพร้อมรูปหน้าจอเข้า Telegram ได้

1. สร้างบอทกับ [@BotFather](https://t.me/BotFather) แล้วเอา **Bot Token** มา
2. ทักบอทของตัวเอง 1 ข้อความ แล้วหา **Chat ID** ของตัวเอง (เช่นจาก [@userinfobot](https://t.me/userinfobot))
3. ในโปรแกรม กด **⚙ ตั้งค่า** แล้วใส่ทั้งสองค่า

ค่าจะถูกเก็บไว้ในไฟล์ `telegram_config.json` ข้างตัวโปรแกรมเท่านั้น
**อย่าแชร์ไฟล์นี้ให้ใคร** เพราะใครได้ token ไปก็ส่งข้อความในนามบอทของคุณได้

## มันทำงานยังไง

บอทมีแค่ 3 ส่วน ทำวนไปเรื่อยๆ

| ส่วน | ทำอะไร | ในโค้ด |
|---|---|---|
| 👁 ตา | แคปภาพเฉพาะหน้าต่างอีมู แล้วปรับเป็นขนาดมาตรฐาน 840x486 | `PrintWindow` (`PW_RENDERFULLCONTENT`) |
| 🧠 สมอง | เอารูปปุ่มที่เตรียมไว้ไปเลื่อนเทียบกับภาพ ถ้าเหมือนเกิน 65% = เจอปุ่ม | `cv2.matchTemplate` (`TM_CCOEFF_NORMED`) |
| 🖱 มือ | ส่งคลิกเข้าหน้าต่างอีมูโดยตรงผ่าน Windows เมาส์จริงไม่ขยับ | `PostMessage` (`WM_LBUTTONDOWN/UP`) |

ส่วนที่ทำให้พฤติกรรมไม่ซ้ำเดิม:
- **จุดกด:** สุ่มแบบ Beta(2,2) ในพื้นที่ด้านในของปุ่ม กระจายทั่วปุ่มแต่เน้นตรงกลาง
- **จังหวะ:** รอก่อนกดและกดค้างไม่เท่ากันทุกครั้ง ทุก 10–20 รอบจะพักยาว 30–90 วินาที
- **กันค้าง:** เทียบภาพ 2 ภาพห่างกัน 0.5 วินาที ถ้าภาพนิ่งเกิน 20 วินาทีจะส่งแจ้งเตือน Telegram

ค่าทั้งหมดปรับได้ใน [`basic_bot/bot_config.py`](basic_bot/bot_config.py)

## รันจากซอร์สโค้ด / build เอง

ต้องมี Windows และ Python 3.11

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

:: รันตรงๆ
python basic_bot\cookie_bot.py

:: หรือ build เป็น .exe (ไฟล์จะอยู่ใน basic_bot\dist\)
build.bat
```

### ออกเวอร์ชันใหม่ (สำหรับผู้ดูแล)

1. แก้ `BOT_VERSION` ใน `basic_bot/bot_config.py`
2. เพิ่มหัวข้อ `## vX.Y.Z` ใน [`CHANGELOG.md`](CHANGELOG.md) (ข้อความนี้จะขึ้นในหน้าต่างอัปเดตของผู้ใช้)
3. commit แล้วรัน `python release.py` เพื่อ build และแพ็กไฟล์ลง `release/`
4. ตรวจไฟล์แล้วรัน `python release.py --publish` เพื่อ push และสร้าง GitHub Release (ต้องล็อกอิน `gh` ก่อน)
